# Portfolio UGC Kheira — kheirakh.com
Le mode d'emploi complet est dans le PDF « Guide-site-kheirakh.pdf ».
- Tout le contenu (textes, liens, photos, vidéos, onglets) est dans `content.json`. Ne le modifie pas à la main : passe par ton espace admin sur app.pagescms.org.
- `.pages.yml` règle l'espace admin. Il doit être envoyé sur GitHub (fichier caché : Cmd + Maj + . dans le Finder pour le voir).
- Le design (tailles, couleurs, polices) est dans `style.css`, dans le panneau de réglages tout en haut.
- Vidéos : MP4 de moins de 25 Mo (HandBrake, preset Social 720p30).
- Polices : kit Adobe Fonts nxi0aao (Sloop Script One). Ajoute Futura PT Book au même projet web.
- Pour voir le site sur ton Mac : VS Code → clic droit sur index.html → Open with Live Server.
